# Santos Laguna (SwiftUI)

App informativa del Club Santos Laguna de Torreón, Coahuila.
Se navega con los botones del menú o deslizando a la izquierda / derecha
(6 pantallas: Inicio, Historia, Campeonatos, Estadio, Ubicación y Cantera).

## Cómo obtener el archivo para Appetize (sin Mac)

1. Sube todo el contenido de esta carpeta al repositorio (incluida la carpeta `.github`).
2. En GitHub entra a la pestaña **Actions** → **Build para Appetize**.
   Se ejecuta solo con cada push a `main`, o con el botón **Run workflow**.
3. Cuando termine (palomita verde), abre la ejecución y descarga el artefacto
   **SantosLaguna-Appetize** (al final de la página).
4. GitHub lo descarga como zip: descomprímelo y dentro está **SantosLaguna.zip**.
5. Sube ese **SantosLaguna.zip** a https://appetize.io/upload (plataforma iOS).

Requisitos: iOS 17 o superior.
